# Synthetic source-change classification (CP-11.02 draft)

This isolated, offline primitive compares two **synthetic** observations for the exact same source and material. It records both immutable observation identities, capture instants, content digests, parser revisions and all original field claims. It produces a draft `change-set-draft-0.1.0` review routing result; it never fetches, authorizes reuse, grants rights, edits records, decides a source is removed, or publishes a release.

`src/changes/classify` (exported as `from src.changes import classify`) accepts two dictionaries conforming to `$defs.observation` in `schemas/change-set.schema.json`. Field path IDs must be unique within each observation; schema and semantic validation fail closed for malformed values, unexpected kinds, cross-source comparisons, reused observation IDs, non-UTC dates and reversed capture chronology. Decimal price amounts are **strings** and require explicit currency and billing unit. All identities are clearly synthetic. Production inputs are rejected.

The result carries ordered `cause_flags` distinguishing raw-byte changes, parser revisions, semantic claim differences and same-byte/changed-claim conflicts. Changed claims retain full `before` and `after` copies; added and missing claims are not automatically interpreted as source additions or deletions. Alias/identity, availability/retirement and price/unit transitions route to critical review; rights/license changes take precedence and hold future operations; evidence and unknown categories remain visible review items. A parser-only or byte-only change also requires inspection rather than silently declaring cosmetic safety or triggering an unrestricted source refetch. Even unchanged results cannot authorize publication.

Run locally, without network or credentials: `python -m unittest discover -s tests -v` from the repository root after installing `requirements-validation.txt`. The synthetic fixtures exercise conflicts, denial, price meter drift, malformed values, parser drift, duplicate paths and observation preservation.

**Not complete:** #54 still requires accepted predecessors #53, #35 and #21 (CP-11.01, CP-07.03, CP-04.04); actual source/material/use decisions, historical observation/evidence receipts, real parser/change qualification, review queue ownership, independent approval and receiving evidence remain absent. This module is neither a production source detector nor a source-rights engine. The frozen builder v1 contract and upstream research authority are unchanged.
