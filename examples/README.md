# Synthetic examples only

Every JSON artifact here describes fictional entities, sources, permissions,
reviewers and claims. No example is a production record, observed measurement,
real rights grant or accepted consumer receipt.

The model, hardware and paper examples demonstrate breadth beyond an LLM list.
Source-use permissions are operation-specific and field-specific. The synthetic
rights decision permits a narrow display case while redistribution remains
unknown; the offline gate denies unknown operations and denies production use
of every fixture. The release fixture has `publication_eligible: false`, no
real approvals, and no signature. Its checksum checks establish byte identity
only.

Run `python scripts/validate_examples.py` and
`python -m unittest discover -s tests -v` to verify positive conformance and the
rejection cases. Keep each fixture's `synthetic: true` marker through derived
artifacts. The validator does not fetch the reserved source URLs.
